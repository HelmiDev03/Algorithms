# Competitive Programming

| Folder | Contents |
|---|---|
| `Codeforces/` | Codeforces rounds (971–985, Educational 170, contest 2036) and `Training/` practice problems |
| `ACM_Training/` | ACM training sheets: `Adhoc/`, `Complexity/`, `STL/` |
| `ECPC_Training/` | ECPC training: `Beginner/` and `Mashup/` contests |
| `ECPC2022/` | ECPC 2022 problems |
| `TCPC2022/` | TCPC 2022 problems |
| `Meta_Hacker_Cup2022/` | Meta Hacker Cup 2022 |
| `Meta_Hacker_Cup2024/` | Meta Hacker Cup 2024 practice round |
| `Meta_Hacker_Cup2025/` | Meta Hacker Cup 2025, rounds 1–3 (one folder per problem with its input/output) |
| `Leet_Code/` | LeetCode solutions, with `Backtracking/` problems grouped together |
| `Odoo_Coding_Test/` | Odoo coding test exercises |

Compile and run a C++ solution: `g++ A.cpp -o a && ./a`
